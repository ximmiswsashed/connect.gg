# TuffyBlud Portal

A sleek, secure desktop portal with a black-and-white design theme.

## Features

- **Secure Login** — Password-protected access
- **Desktop Selection** — Choose between Desktop 1 and Desktop 2
- **Modern UI** — Glassmorphism, animated grid background, floating shapes, smooth page transitions

## Setup

No build tools required. Simply open `index.html` in a browser or deploy to any static hosting service (GitHub Pages, Netlify, Vercel, etc.).

## GitHub Pages Deployment

1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Set source to **main** branch, root directory
4. Your site will be live at `https://<username>.github.io/<repo-name>/`

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Animations, Glassmorphism)
- Vanilla JavaScript (No dependencies)
